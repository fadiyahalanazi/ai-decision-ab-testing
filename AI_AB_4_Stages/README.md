# أثر توصيات الذكاء الاصطناعي على دقة قرارات الأعمال
**AI Recommendations for Business Decision Accuracy**

مشروع ختامي ضمن برنامج **التجارب واختبارات A/B والاستدلال السببي** في **أكاديمية سدايا** (نوفمبر 2026). [GitHub أكاديمية سدايا](https://github.com/SDAIAAcademy).

## الهدف
هل تؤدي إضافة توصيات الذكاء الاصطناعي إلى لوحة بيانات الأعمال إلى تحسين دقة القرارات؟ مقارنة عشوائية A (لوحة دون توصيات) مع B (لوحة مع توصيات)، بتوزيع مستخدمين 50/50. المقياس الرئيسي `correct_decision`، والثانويان `decision_time` و`satisfaction`، والحماية `high_impact_error`.

## البيانات والمنهجية
**البيانات محاكاة بالكامل وليست تجربة حقيقية.** بذرة التوليد 2026. حجم العينة المطلوب 1,468 لكل مجموعة تقريبًا، والتخطيط 21 يومًا بمتوسط 200 مستخدم يوميًا. مستوى الدلالة 5%، القوة 80%، والأثر المستهدف 5 نقاط مئوية. التحليل يشمل SRM، وفترات الثقة، وCUPED، وتصحيح BH، ومقياس الحماية وفحص أثر الحداثة.

## التشغيل
```bash
python -m pip install -r requirements.txt
python main.py
```
يمكن تشغيل الملفات الأربعة منفردة **بالترتيب الرقمي** بعد تثبيت المتطلبات. `main.py` يشغّلها تلقائيًا. لا تحتاج مسارات خاصة بالجهاز ولا ملفات بيانات خارجية.

## مراحل Python
1. `01_question_and_design.py`: السؤال والتصميم وحفظ الإعدادات.
2. `02_sample_size_and_duration.py`: حجم العينة والمدة.
3. `03_analysis_plan_and_results.py`: خطة التحليل ومحاكاة البيانات والتحليل والرسوم.
4. `04_report_and_presentation.py`: التقرير والقرار ومخطط عرض 10 دقائق.

## النتائج
دقة القرار A = **61.09%** وB = **62.68%**؛ الفرق **+1.59 نقطة مئوية**، فترة الثقة 95% **[-1.35، +4.53]**، وقيمة p تقارب **0.289**. CUPED: **+1.76 نقطة**، فترة الثقة **[-1.11، +4.62]**. مقياس الأخطاء عالية الأثر A = **8.06%** وB = **6.08%**.

**القرار:** عدم إطلاق الميزة حاليًا؛ التحسن الرئيسي غير دال إحصائيًا، ويقع الحد الأعلى لفترة الثقة تحت الأثر المستهدف 5 نقاط. الخطوة التالية تحسين التوصيات وإعادة التجربة.

**القيود:** المحاكاة لا تثبت أثرًا على مستخدمين حقيقيين. مقياس الأخطاء عالية الأثر مرتبط مباشرة بصحة القرار في مولد البيانات. التقديرات السنوية إسقاطات غير مؤكدة.

## المخرجات
